# 证据与分析规则

Gate 1、问题树、证据搜索、市场洞察或结论校准读取本文件。它负责行业定义与生命周期、证据类型、信源路由、分析工具选择和信息不足时的降级；不承担 Market Sizing、企业模式或报告结构。

## Gate 1｜确认行业定义与生命周期

提交给用户确认的 Gate 1 至少包括：

1. **定义差异：** 权威、监管、统计、商业和企业口径有哪些实质差异；
2. **工作定义：** 本研究纳入和排除什么，邻近市场是什么；
3. **边界影响：** 该定义如何影响市场数据、竞争样本、价值链和后续结论；
4. **生命周期证据：** 支持与反对当前阶段判断的需求、供给、技术、渗透率、竞争、渠道、资本或监管证据；
5. **阶段判断：** 导入、成长、成熟、衰退、重构或其他更合适阶段，以及细分市场差异；
6. **置信度与缺口：** 判断强度、冲突来源和仍需验证的信息。

行业阶段判断是必选项，但生命周期模型、指标组合和量化方法按行业与证据选择。若一个总标签掩盖细分差异，应分别判断。Gate 1 未获确认不得继续。

## 区分研究内容性质

研究过程持续区分：

| 类型 | 含义 |
|---|---|
| Fact | 来源直接支持、口径明确的事实。 |
| Proxy | 用相邻市场、样本或替代指标代表目标变量。 |
| Calculation | 可由输入和公式复算的结果。 |
| Assumption | 缺少直接观察但为分析所需的假设。 |
| Scenario | 用于测试条件变化的情景值，不是观察事实。 |
| Inference | 基于证据作出的分析推断。 |
| Evidence Gap | 当前证据不足以支持所需精度或结论。 |

在内部证据台账、关键假设、代理数据、Market Sizing 参数和易被误解为事实的推断中显式记录类型。正式报告不逐句打标签；只有数据性质影响读者理解、结论可信度或测算结果时才标明。

## Hard Evidence Rules｜硬证据规则

1. **先定命题再搜来源。** 明确要证明的准确事实、范围、时期和强度。
2. **追溯原始出处。** 优先监管、统计、公司文件、数据库所有者、论文原文或其他第一方来源；二次材料只作发现入口或辅助解释。
3. **来源与结论匹配。** 来源支持什么就写什么，不把企业声称升级为独立事实，不把相关性升级为因果。
4. **保存必要口径。** 记录定义、地域、时期、单位、币种、价格、收入、GMV、出货或其他计量口径。
5. **检查时效。** 动态数据使用最新可得资料；旧数据只在结构判断、历史趋势或缺少替代时使用并注明限制。
6. **识别同源依赖。** 多篇转载不等于多条独立证据；追踪共同的上游数据集和决策性输入。
7. **处理冲突。** 比较定义、样本、价值层、时期和披露动机；不能解决时并列呈现并降低结论强度。
8. **披露推导链。** 计算、桥接、代理和调整必须可复核，假设不得伪装为市场事实。
9. **主动找反证。** 重要结论至少检查失败条件、反向证据或替代解释；缺少反证不等于结论成立。
10. **建议不超过证据。** 证据只能支持方向或候选时，不升级为确定判断或优先建议。

## Source Hierarchy｜信源优先级

按具体命题选择来源，而非给网站固定评级：

1. 法律法规、监管文件、政府统计、标准和公共数据库；
2. 公司公告、财报、招股书、产品与价格文件、合同或运营披露；
3. 数据库所有者、行业协会、研究机构原始报告和学术论文；
4. 有透明方法与引用的专业媒体、咨询或券商研究；
5. 新闻、访谈、渠道资料和高质量二手分析；
6. 聚合页、搜索摘要、转载和无方法材料，仅作线索。

付费或专有数据库不是天然真相。仍需检查定义、样本、覆盖范围、更新周期和可复现性。

## Source Routing｜按命题路由信源

| 命题 | 优先来源 |
|---|---|
| 行业定义、监管、许可、标准 | 法规、监管机构、标准正文、统计分类。 |
| 规模、产量、销量、装机、价格 | 统计机构、数据库所有者、协会原始数据、公司披露。 |
| 企业收入、成本、利润、客户与产能 | 财报、公告、招股书、投资者材料、正式企业文件。 |
| 客户问题、采购与使用行为 | 一手调研、公开调查原始结果、招标、评价、合同或访谈。 |
| 技术性能、成熟度与替代关系 | 标准、论文、专利、测试报告、产品文档和专家证据。 |
| 竞争份额与集中度 | 与目标定义、地域、时期和价值层兼容的原始数据或可审查估算。 |
| 历史趋势与预测 | 可追溯历史数据加透明模型；预测假设必须披露。 |

搜索摘要只能帮助定位来源，不作为正式证据。可用 Wind 等授权数据库时，把它作为可选增强来源；不要索要凭证、假装已访问或因此停止公开研究。

## 建立问题树与证据需求

从 Gate 0 的决策问题反推最少必要分支，例如：

- 行业边界与阶段；
- 市场、客户、场景与需求机制；
- 产品、技术、供给、产业链和价值链；
- 竞争结构、替代方案、代表性企业和经营模式；
- 影响结论的容量、可服务范围或可获得需求；
- 驱动因素、趋势、风险、反向证据和现实验证。

对每个分支写清所需命题、理想信源、可接受代理、失败条件和与最终目的的关系。问题树服务于决策，不要求章节一一对应。

## 从描述走向机制

对重要判断回答：

1. 发生了什么；
2. 为什么发生，机制是什么；
3. 由哪些参与者、激励、约束或资源传导；
4. 哪些证据支持或反对；
5. 对需求、供给、竞争、利润、风险或机会意味着什么；
6. 哪些条件变化会使判断失效。

区分增长结果和增长驱动、领先结果和领先机制、政策存在和政策实际影响、客户兴趣和付费行为。

## 条件式选择分析工具

| 工具 | 何时使用 |
|---|---|
| PEST / 外部环境 | 政策、宏观、社会、技术等外部变化确实改变供需、成本、竞争或可行性时。 |
| 波特五力 | 需要解释结构性盈利、议价权、替代和进入壁垒，且证据支持时。 |
| 产业链与价值链 | 需要说明参与者、收费、价值流动、控制点、瓶颈和利润分布时；完整 Standard / Deep 至少建立基础认知。 |
| SWOT | 已有充分事实，需要压缩特定进入者与环境的匹配关系时；不用于发现事实。 |
| 单位经济性 | 价格、贡献、获客、留存、利用率、营运资金或规模条件会改变判断时。 |
| Market Sizing | 容量、可服务范围或可获得需求影响决策，或用户单独要求时。 |
| Benchmark | 存在可比企业、区域、渠道、产品或单位产出，并能解释可比性时。 |

工具不是固定章节。不能增加受证据支持的新洞察时就省略。

## 证据不足时降级

不要因局部缺数据停止整个研究：

1. 完成可靠部分；
2. 尝试定义匹配的替代来源或 Proxy；
3. 只能支持范围时输出区间，只能支持方向时输出定性判断；
4. 关键筛选比例无来源时标为 Assumption；
5. 企业未披露写“未披露（Not disclosed）”，公开材料不足写“公开证据不足（Insufficient public evidence）”；
6. 降低结论精度、置信度和建议强度，并给出验证办法。

不得为了结构完整制造数字、因果关系、企业事实或确定结论。

## 完成检查

- 工作定义、地域、时期、价值层和计量口径前后一致；
- 生命周期有支持与反向证据、细分差异和置信度；
- 重要结论可追溯到匹配来源，冲突和同源依赖已处理；
- 事实、代理、计算、假设、情景、推断和缺口保持区分；
- 分析解释机制、条件和含义，而非只堆事实；
- 工具按问题选择，结论强度没有超过证据。
