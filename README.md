# Industry Research Skill

用于 Codex / Agent 的行业研究 Skill。

## 能做什么

- 行业定义与生命周期判断
- 市场规模测算
- 产业链与价值链分析
- 竞争格局研究
- 商业模式与盈利能力分析
- 第一轮行业地图
- 用户主导的重点深挖
- 最终标准行业研究报告整合

## 工作流程

Gate 0
→ Gate 1
→ Gate 2
→ Phase 3 第一轮完整研究
→ Phase 4 重点深挖
→ Phase 5 最终报告整合

将本仓库复制到：
